# Sport Zone Backend

> Plataforma de servidor para la gestión y distribución de uniformes deportivos.

## Descripción

**Sport Zone Backend** es una aplicación de servidor construida con NestJS que gestiona un catálogo completo de uniformes deportivos. Esta plataforma permite a los usuarios explorar, descargar y gestionar una amplia variedad de uniformes para diferentes deportes.

### Características principales

- 🎽 **Catálogo extenso de uniformes**: Miles de diseños organizados por deporte y estilo (fútbol, baloncesto, béisbol, hockey, running y gaming)
- 📥 **Sistema de descargas**: Gestión eficiente de descarga de recursos de uniformes
- 💾 **Base de datos robusta**: Almacenamiento seguro de información de uniformes y usuarios
- 🔌 **API RESTful**: Endpoints bien estructurados para consumo desde aplicaciones cliente
- 🔐 **Autenticación**: Sistema seguro de validación de usuarios
- ⚡ **Rendimiento**: Arquitectura moderna y escalable con NestJS

## Instalación
